# Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Store page with Epic's free games (now / next) and a Store window showing Epic's real website, signed in until Log out.

**Architecture:** A pure parser in `fishy-core/src/store.rs` turns Epic's public promotions JSON into two lists; the Tauri app fetches it (10-minute memory), opens a non-private `epic-store` window with no IPC, refreshes the Library when it closes, and Log out closes it and clears the shared WebView2 data. A Svelte `StorePage` shows the lists.

**Tech Stack:** Rust (reqwest, serde_json, chrono, wiremock tests), Tauri 2, Svelte 5 + vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-fishy-client-design.md` §6o.

## Global Constraints

- Fishy Client never buys, claims or clicks anything on Epic's pages.
- Promotions URL exactly `https://store-site-backend-static-ipv4.ak.epicgames.com/freeGamesPromotions?locale=en-US` (no country).
- Free = `discountSetting.discountPercentage == 0`. Page link `https://store.epicgames.com/p/<slug>`; fallback `https://store.epicgames.com/free-games`; Open Epic's store = `https://store.epicgames.com/`.
- Store window: label `epic-store`, title "Epic Games Store", 1200×800, not incognito, no IPC (capabilities stay `["main"]`).
- Copy, exactly: "Open Epic's store", "Free now", "Free next", "Free until *date*", "Free from *date*", "Get on Epic", "View on Epic", "In your Library", "Nothing right now.", "Couldn't load the free games. Check your internet, then press Try again.", "Try again", "Fishy Client opens Epic's page; you get the game there yourself."
- Logs: "store: free games loaded (N now, M next)", "store: couldn't load the free games", "store: window opened", "store: window closed" only.
- Dates shown like the rest of the app (`toLocaleDateString` with month short + day).

## Review Focus

1. Offers with several promotional offers where only one is 0%: counted free only by the 0% one, with that one's dates. Test in Task 1.
2. An offer free now whose `endDate` already passed (stale cache on Epic's side): left out. Test in Task 1.
3. Missing/`null` fields (`promotions: null`, `productSlug: null`, `items` missing, `keyImages` empty): no crash, sensible fallback. Test in Task 1.
4. Navigation rule with look-alike hosts (`epicgames.com.evil.net`, `http://` pages): kept out of the window. Test in Task 1.
5. Store window already open when Get is pressed: it navigates and comes to the front, no second window. By hand in Task 2.

### Task 2: Tauri commands and the Store window

**Files:** Create `app/src-tauri/src/store_window.rs`; modify `app/src-tauri/src/lib.rs` (state, commands, `logout`).

**Interfaces:**
- State `AppStore { client: StoreClient, cache: Mutex<Option<(Instant, FreeGames-without-owned json bytes)>> }` — keep the raw bytes and time; parse per call so `owned` uses the current Library cache.
- `#[tauri::command] async fn store_free_games(force: bool) -> Result<FreeGames, String>`: bytes from memory if younger than 10 min and not `force`, else fetch; owned ids from the Library cache's `catalog_item_id`s; error text = the spec's sentence.
- `#[tauri::command] fn store_open(url: Option<String>) -> Result<(), String>`: only `store_nav_allowed` URLs (else the store home); open or focus+navigate the `epic-store` window (`WebviewWindowBuilder`, not incognito, `on_navigation` → `store_nav_allowed`, `on_new_window` → Allow), log "store: window opened"; on `WindowEvent::Destroyed` log "store: window closed" and emit `store-closed` to `main`.
- `logout`: close `epic-store` if open, then `main` window `clear_all_browsing_data()` (log a warning on failure, don't fail the logout).
